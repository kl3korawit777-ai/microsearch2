## ลำดับงานของเนื้อหา (แก้ 13 พ.ย. 2026 ตามที่คุณขอ: หาข้อมูลก่อน แล้วค่อยใส่เว็บ)
1. **ค้นคว้า** → ร่างลงไฟล์พักใน `research/` ยังไม่แตะ `data/organisms`
   - `research/<group>.md`: ข้อความบรรยายภาษาไทย ชนิดละหัวข้อ `## <id>` และหัวข้อย่อยคงที่ 6 หัว (ส่วน 2, 4, 5, 6, 7 และ disease/warning)
   - `research/<group>.data.json`: ข้อมูลที่ humanizer ห้ามแตะ (ผู้ตั้งชื่อ ชื่อพ้อง accepted_name ลักษณะ refs iucn)
2. **ทำให้อ่านง่าย** → คุณรัน /humanizer กับ `research/<group>.md` (กลุ่มละครั้ง)
3. **นำเข้า** → คำสั่ง `import-research` แปลงไฟล์พักเป็น `extra_th` แล้วตรวจว่า humanizer ไม่เปลี่ยนข้อเท็จจริง:
   หัวข้อครบ, ตัวเลขและหน่วย ชื่อวิทยาศาสตร์ และเลขอ้างอิงตรงกับฉบับร่างที่ commit ไว้ ถ้าไม่ตรงให้รายงานแทนการนำเข้า
4. **แปลอังกฤษ** (R9) จากภาษาไทยที่นำเข้าแล้ว

## สภาพ repo ตอนนี้ (อ่านจาก commit 4c4fdf5)
- เฟส 0–7 เสร็จ: 145 ชนิด, ภาษาอังกฤษครบ, `taxon_ids` (GBIF/NCBI) ครบ, รูปจริง 140/145 ชนิดพร้อมเครดิต
- หน้าชนิดมี 3 แท็บ: **ลักษณะ** (traits + `traitsExtra`), **ความสำคัญ** (`why`), **ชื่อ** (`name`) + กล่อง `aside`
  แต่มีแค่ *Halobacterium salinarum* ที่มี `extra_th` ครบ ชนิดอื่นแสดงแค่สรุป 1–2 ประโยคและตารางลักษณะ 3–5 แถว
- `extra_th` / `extra_en` ใน schema เป็น object ว่างที่ไม่มีโครงสร้าง → ต้องกำหนดก่อนเติมเนื้อหา
- ค้างจาก v1.0: ชื่อชนิดที่ฐานข้อมูลเปลี่ยนแล้ว 3 ชนิด (*Aspergillus oryzae* → *A. flavus* ใน GBIF, *Giardia intestinalis* → *G. duodenalis*, *Physarum polycephalum* → *Badhamia polycephala* ใน NCBI)

## เนื้อหาหน้าชนิด 8 ส่วน
ตัดออกตามที่คุณสั่ง: รูป (มีแล้วจากเฟส 6), เชื่อมบทเรียน, ในประเทศไทย
| ส่วน | เนื้อหา | ที่เก็บใน JSON | แสดงที่ |
| --- | --- | --- | --- |
| 1 หัวเรื่อง | + ผู้ตั้งชื่อและปี, ชื่อพ้องที่ยังพบในตำรา | `authority`, `synonyms` (ใหม่) | หัวหน้า |
| 2 รู้จักใน 30 วินาที | 2–3 ประโยค: เป็นอะไร อยู่ที่ไหน สำคัญอย่างไร | `extra.lede` (มีแล้ว) | ใต้หัวเรื่อง |
| 3 ลักษณะเด่น | ตารางลักษณะ 6–9 แถว (ตารางถัดไป) | `traits` + `extra.traitsExtra` | แท็บลักษณะ |
| 4 การดำรงชีวิต | แหล่งที่อยู่, การได้อาหาร/พลังงาน, ความสัมพันธ์กับสิ่งมีชีวิตอื่น | `extra.life` (ใหม่) | แท็บใหม่ "การดำรงชีวิต" |
| 5 การสืบพันธุ์และวงชีวิต | ฟังไจ โพรทิสต์ พืช ปรสิต: ลำดับขั้น; โพรแคริโอต: 1 ประโยค | `extra.lifecycle` (ใหม่) | แท็บเดียวกับส่วน 4 |
| 6 ความสำคัญ | แยกตามแท็ก แท็กละ 1–2 ประโยค | `extra.why` (มีแล้ว) | แท็บความสำคัญ |
| 7 ชื่อนี้มาจากไหน + เกร็ด | ความหมายชื่อสกุล/ชนิด + เรื่องน่ารู้ 1 ข้อ | `extra.name`, `extra.aside` (มีแล้ว) | แท็บชื่อ + กล่อง |
| 8 อ้างอิง | 2–5 แหล่ง: ชื่อ, URL, วันที่เข้าถึง | `refs` (ใหม่) | ท้ายหน้า |

ส่วนเพิ่มเฉพาะบางชนิด (`extra.disease`, `extra.warning`, `iucn`):
- เชื้อก่อโรคและปรสิต: โรค อาการหลัก การติดต่อ การป้องกัน กลุ่มยาแบบกว้าง ไม่มีชื่อสูตรหรือขนาดยา
- เห็ดพิษและสัตว์มีพิษ: กล่องคำเตือน + สิ่งที่มักเข้าใจผิด
- พืชและสัตว์: หมวด IUCN + ลิงก์ (ข้อมูลจาก API อย่างเดียว ไม่คัดลอกข้อความประเมิน)

## ขั้นตอนต่อหนึ่งชนิด
1. ยืนยันชื่อ ผู้ตั้งชื่อ ชื่อพ้อง (GBIF + ฐานข้อมูลเฉพาะกลุ่ม; ID มีแล้ว ตรวจเฉพาะว่ายังตรง)
2. ลักษณะมีโครงสร้าง จากฐานข้อมูลเฉพาะกลุ่ม
3. เนื้อหาส่วน 2–7 จากตำรา review และเว็บหน่วยงาน
4. ศัพท์ไทยเทียบราชบัณฑิตยสภา
5. อ้างอิงครบ → `validate` + `coverage` → Sheet สถานะ "เสร็จ"
