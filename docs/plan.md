# แผน: Microsearch 2.0 เว็บข้อมูลสิ่งมีชีวิต 6 กลุ่ม (แบคทีเรีย อาร์เคีย ฟังไจ โพรทิสต์ พืช สัตว์)
ชื่อโปรเจกต์: **Microsearch 2.0** · repo: `microsearch2` (GitHub Pages)
สถานะ: **อนุมัติแล้ว เริ่มสร้างจริง 13 พ.ย. 2026** (ต้นแบบผ่านการตรวจของคุณแล้ว)
วิธีทำงาน: แต่ละเฟสมี prompt ให้วางใน Claude Code (ไฟล์ `claude-code-prompts.md`)

## จุดตั้งต้น
- ต้นแบบ `design/prototype.html` คือแบบที่อนุมัติแล้ว เว็บจริงต้องหน้าตาและพฤติกรรมเหมือนต้นแบบ
- `seed/` คือข้อมูลที่ดึงออกจากต้นแบบ: 145 ชนิด (แบคทีเรีย 24, อาร์เคีย 9, ฟังไจ 19, โพรทิสต์ 25, พืช 30, สัตว์ 38),
  490 ชื่อในแผนผังพร้อมคำอ่านและคำอธิบายไทย/อังกฤษ ทุกรายการเป็น `ai_draft`
- โครงที่ใช้ซ้ำจาก repo `nexus-cells`: JSON แยกไฟล์, สคริปต์ Python ตัวเดียว (validate / fetch / build / images / coverage),
  GitHub Actions ตรวจข้อมูลก่อน deploy, i18n, PWA, `CLAUDE.md` ที่ผูกกับ Project Hub
- แหล่งตรวจอนุกรมวิธาน: GBIF API (ไม่ต้องมี key) + NCBI E-utilities (≤3 คำขอ/วินาที) ไม่ใช้ LPSN
- โพรทิสต์จัดตามซูเปอร์กรุ๊ปที่เขียนเองใน `groups.json` เพราะ NCBI/GBIF ไม่มีขั้นนี้
