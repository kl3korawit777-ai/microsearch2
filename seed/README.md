# Seed data จากต้นแบบ Microsearch 2.0 (13 พ.ย. 2026)

ดึงออกมาจาก `design/prototype.html` เพื่อใช้เป็นข้อมูลตั้งต้นของเว็บจริง ทุกรายการเป็น `review: ai_draft` (Claude ร่าง ยังไม่ได้ตรวจ)

| ไฟล์ | เนื้อหา |
| --- | --- |
| `organisms/<group>.json` | 145 ชนิด แยก 6 กลุ่ม: ชื่อวิทยาศาสตร์ ชื่อไทย คำอ่าน ลำดับชั้น ป้ายระดับ (hs/uni) แท็กความสำคัญ คำอธิบาย ลักษณะ |
| `taxa.json` | ทุกชื่อในแผนผัง (โดเมนถึงสกุล): ลำดับขั้น คำอ่าน คำอธิบายว่าทำไมจัดอยู่ในกลุ่มนี้ ทั้งไทยและอังกฤษ |
| `groups.json` | 6 กลุ่ม ไฟลัม/ซูเปอร์กรุ๊ป ลำดับขั้นต่อกลุ่ม ลักษณะ ค่าลักษณะ (ไทย/อังกฤษ) ตัวกรอง แท็ก ป้ายระดับ |
| `illustrations.json` | ภาพวาด SVG ชั่วคราว (ใช้จนกว่าจะมีรูปจริง) |
| `i18n/{th,en}.json` | ข้อความ UI ของต้นแบบ |

ช่องที่ยังว่าง: `name_en`, `summary_en`, `traits_text_en` (ส่วนใหญ่), `taxon_ids`, `images`
ลำดับชั้นทั้งหมดเขียนจากความรู้ของ Claude ต้องเทียบกับ GBIF/NCBI ก่อนเปิดตัว
