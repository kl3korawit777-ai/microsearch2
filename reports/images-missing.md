# ชนิดที่ยังไม่มีรูปจาก Wikimedia Commons

สร้างจาก `python scripts/microsearch.py images` รับเฉพาะ license CC0, CC BY, CC BY-SA, Public domain ที่ระบุชัดเจน
ชนิดในรายการนี้ใช้ภาพวาดเดิมต่อ (ห้ามใช้รูปที่ license ไม่ชัด)

ชนิดทั้งหมด 145 ชนิด มีรูป 141 ชนิด ไม่มีรูป 4 ชนิด

| ชนิด | กลุ่ม | เหตุผล |
| --- | --- | --- |
| *Nitrobacter winogradskyi* (`nitrobacter-winogradskyi`) | bacteria | ไม่มีรูปที่ผ่านเกณฑ์ (เห็น 1 ไฟล์; ตัดทิ้ง: format 1) |
| *Amanita exitialis* (`amanita-exitialis`) | fungi | ไม่มีรูปที่ผ่านเกณฑ์ (เห็น 3 ไฟล์; ตัดทิ้ง: format 2, not-this-species 1) |
| *Spirogyra varians* (`spirogyra-varians`) | protists | ไม่มีรูปที่ผ่านเกณฑ์ (เห็น 5 ไฟล์; ตัดทิ้ง: format 5) |
| *Gracilaria fisheri* (`gracilaria-fisheri`) | protists | ไม่พบรูปในหมวดหมู่หรือผลค้นหา (เห็น 0 ไฟล์) |
