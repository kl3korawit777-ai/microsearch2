# Microsearch 2.0

เว็บความรู้เรื่องสิ่งมีชีวิต 6 กลุ่ม (แบคทีเรีย อาร์เคีย ฟังไจ โพรทิสต์ พืช สัตว์)
สำหรับนักเรียน ม.ปลาย และนักศึกษา เนื้อหาสองภาษา (ไทย/อังกฤษ)
เป็น static site บน GitHub Pages ข้อมูลเป็น JSON แยกไฟล์ และใช้สคริปต์ Python ตัวเดียวตรวจ/ดึง/build
(โครงเดียวกับ `nexus-cells`)

**สถานะ:** เฟส 0–3 (ข้อมูล + validate + รายงานอนุกรมวิธาน + เว็บหน้าแรก/กลุ่ม/ชนิด/แหล่งข้อมูล) แผนผังโดเมน ตารางเปรียบเทียบ ยังไม่มี (เฟส 4)

## เอกสาร
- [docs/plan.md](docs/plan.md) แผนที่อนุมัติแล้ว: เฟส 0–7 บันทึกการตัดสินใจ และกฎทำเสมอ/ไม่ทำ
- [CLAUDE.md](CLAUDE.md) คำสั่งสำหรับ AI ประจำ repo
